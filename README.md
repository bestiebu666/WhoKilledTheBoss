# 谁杀死了老板（Who Killed The Boss）

一款使用 **Godot 4.7.2** 制作的中文 3D 剧情探索游戏。玩家以“悬浮记录仪”的视角进入办公室，在人物与陈设之间搜集线索、回答判断题，并逐步推进剧情。

当前版本已开放 **第一幕「设计部」**，包含三轮探索与判断题；第二幕、第三幕仅保留锁定入口，尚未实现对应场景和玩法。

## 主要功能

- **完整进入流程**：波普风标题页、前情提要、选幕页与第一幕场景切换。
- **3D 办公室探索**：16 × 12 米室内场景，包含家具、建筑构件与四名 NPC；已交付的 GLB 模型会自动替换灰盒。
- **两种移动方式**：点击地面自动走近目标，也可使用 WASD 移动；按住鼠标左键拖动可环顾四周。
- **三轮搜证流程**：每轮阅读全部指定探索点后自动进入判断题，完成后播放轮末过场并刷新线索。
- **判断题反馈**：答对解锁新剧情，答错获得新线索，并可标记相关探索点的矛盾状态。
- **线索记录与回顾**：右侧记录跨轮累积的新剧情和新线索；“回顾”可按当时轮次重看结论与已答判断题。
- **NPC 表现**：角色头顶思考框、随轮次变化的台词和待机动作。
- **手绘风 UI**：标题、选幕、纸卡、记录面板使用项目内美术资源，内置中文字体。
- **背景音乐**：BGM 跨页面持续播放，音频管理器支持等功率交叉淡化。
- **桌面与 Android 配置**：桌面使用 Forward+，移动端使用 GL Compatibility，并配置 ETC2/ASTC 纹理导入。
- **开发自检与工具**：包含端到端自检场景、模型槽位检查、模型预处理和文案表格处理脚本。

## 技术栈

| 部分 | 技术 |
|---|---|
| 游戏引擎 | Godot 4.7.2 stable |
| 游戏逻辑与 UI | GDScript；场景与大部分 UI 由代码构建 |
| 场景与模型 | Godot 3D、GLB / glTF 模型 |
| 内容配置 | JSON（剧情、探索点、场景布局、模型映射） |
| 音频 | Ogg Vorbis |
| 辅助工具 | Python；部分模型工具需要 Blender |
| 目标平台 | Windows Desktop、Android（arm64-v8a） |

## 环境要求

### 直接运行与开发

- **Godot 4.7.2 stable**。建议使用完全一致的小版本，避免导入和导出行为差异。
- Windows 上可直接运行仓库中的 `启动游戏.bat` 或 `用Godot打开工程.bat`，但需按脚本提示准备 Godot 可执行文件。
- 项目包含高精度模型与贴图，首次导入和启动可能较慢，并需要足够磁盘空间。

### Android 导出（可选）

- 与 Godot 4.7.2 完全匹配的导出模板。
- JDK 17。
- Android SDK、Build-Tools 与对应平台组件。
- 自己的发布密钥库；**仓库不包含密钥库、签名密码或本机导出预设**。

详细配置与验证方法见 [`docs/安卓APK打包说明.md`](docs/安卓APK打包说明.md)。

## 安装与运行

### 方式一：使用 Godot 编辑器

1. 克隆仓库：

   ```bash
   git clone https://github.com/bestiebu666/WhoKilledTheBoss.git
   cd WhoKilledTheBoss
   ```

2. 在 Godot 项目管理器中导入本目录的 `project.godot`。
3. 等待模型、贴图与字体完成首次导入。
4. 按 **F6/F5** 运行；工程主入口为 `scenes/app.tscn`，正常完整运行请使用 **F5**。

### 方式二：命令行

在工程根目录执行，将命令中的可执行文件替换为本机 Godot 4.7.2 路径：

```bash
# 首次导入资源
"<Godot 4.7.2 可执行文件>" --headless --path . --import

# 运行游戏
"<Godot 4.7.2 可执行文件>" --path .

# 打开编辑器
"<Godot 4.7.2 可执行文件>" --editor --path .
```

Windows 命令行诊断建议使用 Godot 的 `_console.exe`，以便直接查看标准输出。

## 使用说明

1. 在标题页选择“开始游戏”，或先阅读“前情提要”。
2. 在选幕页进入已解锁的第一幕“设计部”。
3. 观察带感叹号的家具与 NPC，点击后角色会走近并打开对应内容。
4. 读完本轮要求的全部探索点后，依次回答自动出现的判断题。
5. 完成轮末过场进入下一轮；第三轮结束后进入第一幕结束页。

| 操作 | 效果 |
|---|---|
| 按住鼠标左键拖动 | 环顾四周 |
| 单击地面 | 移动到目标位置 |
| 单击物件或 NPC | 走近并查看内容 |
| WASD | 按当前视角移动，并取消当前点击移动目标 |
| ESC | 关闭允许关闭的弹窗；判断题等必须作答的流程不能跳过 |
| 右上角“回顾” | 查看已到达轮次的结论和已答判断题 |

游戏进度保存在当前运行实例中；**尚未实现存档、读档、账号或联网功能**。

## Android 导出

1. 复制脱敏示例，生成本机私有预设：

   ```bash
   cp export_presets.example.cfg export_presets.cfg
   ```

2. 在本机 `export_presets.cfg` 中填写自己的密钥库路径、别名和密码，并确认 Android SDK/JDK 配置。
3. 使用 Godot 导出界面，或执行：

   ```bash
   "<Godot 4.7.2 console 可执行文件>" --headless --path . \
     --export-release "Android" "build/android/WhoKilledTheBoss.apk"
   ```

`export_presets.cfg`、`build/`、密钥库和 APK 均已被 `.gitignore` 排除，不要将其强制加入版本库。

## 自检

工程提供 `scenes/selftest.tscn`，用于检查移动、探索、弹窗、判断题、轮次推进和回顾等逻辑：

```bash
"<Godot 4.7.2 console 可执行文件>" --headless --path . res://scenes/selftest.tscn
```

无头环境对窗口尺寸和动画时序的处理可能与桌面不同；排查时应区分环境差异与真实回归。既有验证记录见 [`docs/开发记录.md`](docs/开发记录.md)。

## 修改内容与模型

- **剧情和界面文案**：修改 `data/*.json`；同一探索点在不同轮次可以有不同文案。
- **场景位置和尺寸**：修改 `data/room.json`、`data/objects.json`。
- **模型对应关系**：以 `data/model_map.json` 为准；将 GLB 放入 `assets/models/` 后，运行时按映射自动替换灰盒。
- **模型规范**：见 [`assets/models/README.md`](assets/models/README.md) 和 `docs/建模对照表.html`。

## 注意事项

- 当前仅第一幕可玩，不要将第二幕、第三幕的入口视为已完成内容。
- 核心游戏可离线运行，无服务器依赖。
- 高精度模型使源码仓库和导出包体积较大；克隆、导入及低性能设备运行时需要预留足够时间和空间。
- `.godot/` 是可再生成的本地缓存，首次克隆后由 Godot 重新创建，不需要从仓库获取。
- 本仓库未单独提供开源许可证。代码、文案、美术、字体、音频与模型在公开再分发或商用前，应分别确认相应权利与授权范围。

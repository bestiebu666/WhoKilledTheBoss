替换三步HOW TO SWAP

  1. 照着做。把 assets/placeholders/greybox_reference.glb 拖进 Blender，每个方块的名字就是槽位名，位置和尺寸都是真值 —— 照着描，或者干脆当比例参照。
  2. 照名字导出。原点放底面中心、Y-up、Apply Transform（location 也要 Apply），导出 glb，文件名必须等于「导出文件名」那一列，例如 SM_F_Desk.glb。一个模型顶多个位置的时候（表里标了「×N 处复用」），只导这一份就行。
  3. 丢进去就行。放进 assets/models/，重开游戏自动替换。控制台会播报「已换真模型 N · 仍是灰盒 M」，尺寸或面数不对还会点名提醒。

命名规则与建模规范CONVENTIONS

  • 命名SM_<Zone>_<Name>[_<Variant>]　Zone：B 建筑 / F 家具 / J 可交互 / A 角色 / FX 特效
  • 单位米。尺寸照表里给的来（已含统一缩放），不要自己再缩。
  • 原点放在物体底面中心（底面贴在表里的 y 上），没有例外 —— 主角是相机本身，不做模型。
  • 朝向面向 -Z（glTF 默认正面）。椅子、人、有正反面的东西都照这个来。表里写了「绕 Y 轴转 X°」的位置是场景替它转的，你照 0° 做即可，别自己做反。两组工位背靠背拼成一个岛，就是靠这个字段把其中一组翻 180°。
  • 材质Metallic 0、Roughness 0.85、只用 Base Color。不做法线贴图、不做 ORM、不做真实反射。
  • 配色六组基色：暖木 #C8A57B 米白 #EDE7DC 雾蓝 #8FA9C4 鼠尾草绿 #9BB39A 珊瑚红 #D98C6A 墨灰 #4B4A47。
  • 复用表里标了「×N 处复用」的，就是多个位置共用同一个模型文件。只做一个、只导出一份，不要加 _01 / _02 后缀。
  • 面数表里给了每个模型的预算。人森风不怕少，超了就砍 —— 游戏会自动提醒。
